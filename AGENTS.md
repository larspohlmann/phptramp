# Agent instructions

All agent instructions for this repository live in **[CLAUDE.md](CLAUDE.md)** —
read that file in full before doing anything else. Everything in it applies to
every coding agent regardless of tool or model: the `composer check` gate, the
mutation-testing PR gate, the Clean Code house style, strict fixture-first TDD,
the conventional-commit format with issue numbers, and the git-flow workflow.

Phase implementation plans live in `docs/plans/phase-N.md`; the master plan and
frozen semantics are in [docs/plan.md](docs/plan.md).
